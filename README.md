# 📝 TaskFlow - モダン ToDoList Web アプリケーション

PHP 8.3 と MySQL をバックエンドに採用した、美しくレスポンシブな ToDo リスト管理アプリケーションです。

---

## ✨ 主な機能

- **タスクのCRUD管理**:
  - タスクの追加・編集・削除
  - ワンクリックでの完了 / 未完了切り替え（スムーズなアニメーション付き）
- **優先度 & カテゴリ分類**:
  - 優先度（高・中・低）のバッジと視覚的ハイライト
  - 複数カテゴリ（仕事、プライベート、買い物、学習、健康、一般）
- **期限管理 & アラート**:
  - 期限日時の設定（今日・明日・X日後・期限切れアラート表示）
- **リアルタイム検索 & 絞り込み**:
  - タイトル・詳細テキストの即時検索（ショートカットキー `/` 対応）
  - 状態別タブフィルター（すべて、未完了、完了済み、今日が期限、期限切れ）
  - カテゴリ & 優先度による複合フィルタリング
  - 複数のソート順（作成日順、期限日順、優先度順、名前順）
- **進捗ダッシュボード & 統計**:
  - 完了率プログレスバー
  - 総タスク数、未完了数、完了数、期限切れ件数のリアルタイムカウンター
- **ダークモード / ライトモード対応**:
  - OS設定の自動認識および手動切り替え（ローカルストレージに状態保存）
- **RESTful API 連携**:
  - Fetch API によるページ再読み込みのない非同期操作

## 🚀 起動・使用方法

### 1. MySQL の設定 (`config.php`)
デフォルトではローカルの MySQL (`127.0.0.1:3306`)、データベース名 `todolist_app`、ユーザー `root`、パスワード空 で動作します。

必要に応じて `config.php` を編集して接続情報を設定してください：

```php
return [
    'host'     => '127.0.0.1',
    'port'     => '3306',
    'dbname'   => 'todolist_app',
    'user'     => 'root',        // あなたのMySQLユーザー名
    'password' => '',            // あなたのMySQLパスワード
    'charset'  => 'utf8mb4'
];
```

※ 初回接続時にデータベースおよびテーブルは自動的に作成されます。手動で作成したい場合は `schema.sql` をインポートしてください。

### 2. 組み込み Web サーバーの起動
ターミナルで本ディレクトリ（`ToDoList`）に移動し、以下のコマンドを実行します：

```bash
php -S localhost:8000
```

### 3. ブラウザでアクセス
ブラウザで以下の URL を開きます：
[http://localhost:8000](http://localhost:8000)

## 🔌 API エンドポイント

| メソッド | エンドポイント | 説明 |
|---|---|---|
| `GET` | `/api.php?action=list` | タスク一覧取得（フィルター・検索・ソート指定可） |
| `POST` | `/api.php?action=create` | 新規タスクの作成 |
| `POST` | `/api.php?action=update` | タスク情報の更新 |
| `POST` | `/api.php?action=toggle` | 完了状態のトグル切り替え |
| `POST` | `/api.php?action=delete` | タスクの削除 |
| `POST` | `/api.php?action=clear_completed` | 完了済みタスクの一括削除 |
| `GET` | `/api.php?action=stats` | タスク統計データ・進捗率の取得 |
| `GET` | `/api.php?action=categories` | カテゴリ一覧と各件数の取得 |
| `POST` | `/api.php?action=add_category` | カスタムカテゴリの追加 |
